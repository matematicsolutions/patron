=================================================================

PATRON's desktop installer redistributes a Windows build of Tesseract OCR.
Tesseract's own license (Apache-2.0) and its AUTHORS file are in
`ocr/tesseract/doc/`. This file carries the notices of the libraries linked
into that build, as reported by `tesseract --version`:

  Leptonica 1.84.1, libjpeg-turbo 3.0.1, libpng 1.6.43, libtiff 4.6.0,
  zlib 1.3, libwebp 1.4.0, libgif 5.2.1, OpenJPEG 2.5.2

Verified against the bundled binary on 2026-08-18. Full license texts and
sources live at the projects' own sites, linked per entry below.

How to check this yourself
--------------------------
Run `ocr/tesseract/tesseract.exe --version` in an installed PATRON: it prints
the exact library versions this file documents. If a version differs from the
list above, this file is stale - report it as a bug.
